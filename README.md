# Машинное обучение на графах

Работы по курсам графового машинного обучения и анализа графов в магистратуре.
От базовой работы с `networkx` до графовых нейросетей и итогового проекта
по анализу динамики графа цитирований.

## Итоговый проект

Граф цитирований **`ogbn-arxiv`** из Open Graph Benchmark (статьи arXiv по
компьютерным наукам) нарезан на срезы по годам публикации. По каждому срезу
посчитаны число вершин и ребер, плотность, компоненты связности и средняя длина
пути, построены графики их динамики. Срезы выгружаются в формате для Neo4j.

Во второй части в каждом срезе выделены сообщества алгоритмом Louvain и
отобраны влиятельные кластеры. Каждому сообществу дается оценка как взвешенная
сумма средней промежуточной центральности, плотности и близости вершин внутри
кластера. Отдельно замерено время расчета на каждом шаге.
