# Машинное обучение на графах

Реализации и эксперименты по курсу графового машинного обучения: от базовой
работы с `networkx` до предсказания свойств вершин на реальном графе.

## Содержание

| Файл | Тема |
|---|---|
| `graphml1.py` … `graphml10.py` | Пошаговые работы курса: представление графов, метрики центральности, обход, кластеризация, эмбеддинги вершин |
| `атг_сем1.py`, `атг_сем3,4.py`, `атг_сем5,6.py`, `атг_сем_7,8.py` | Семинарские задачи по анализу и теории графов |
| `проект.py` | Итоговый проект |
| `4_задание_экзамен.py` | Экзаменационное задание |

## Итоговый проект

Предсказание свойств вершин (node property prediction) на графе
**`ogbn-arxiv`** из Open Graph Benchmark — сети цитирований статей arXiv по
компьютерным наукам, где нужно классифицировать статью по тематической
рубрике на основе структуры цитирований и признаков вершин.

## Стек

`networkx` · `ogb` (Open Graph Benchmark) · `numpy` · `matplotlib` ·
`holoviews` / `bokeh` · `deap`

## Как запускать

Файлы выгружены из Google Colab и сохраняют его структуру — зависимости
устанавливаются в первых ячейках каждого скрипта.

```bash
pip install networkx ogb numpy matplotlib holoviews bokeh deap
python graphml1.py
```
